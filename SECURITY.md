# Security policy

## Scope

EvilCorp intentionally contains insecure patterns for mobile security education. The
documented challenge behavior is not considered a project vulnerability.

Please report issues that escape the training boundary, including unintended access to
real services, undisclosed collection, dependency compromise, build/release tampering,
or behavior that affects systems outside the app's local lab context.

## Reporting

Use GitHub's private vulnerability reporting feature for repository-level security
issues. Do not include real credentials or personal data in a report.

## Lab safety

Run the app on a dedicated simulator or disposable test device. Do not sign in with a
personal Apple Account, reuse real passwords, or install it on a production device.
